# 屏幕学习助手 · Screen Study Assistant

读到不懂的地方，按快捷键框选文字，让 AI 解释，并自动保存为本地文字笔记。

项目原创代码使用 [MIT License](LICENSE)。随项目提供的 MathJax 公式资源使用 Apache-2.0，许可证随资源保留；第三方依赖按各自许可证使用。

当前版本提供 **一个 iOS 风格的设置页面 + 一个可关闭的回答悬浮窗**。已在 macOS Apple Silicon 上实现并测试。

## 启动

双击 `dist/ScreenStudyAssistant.app` 或 `start.command`。从源码运行：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
chmod +x start.command scripts/build_macos.sh
python -m screen_study_assistant
```

### macOS 更新与录屏授权

开发版默认使用临时（ad-hoc）签名。macOS 将其身份绑定到具体版本的代码哈希；重新打包后，即使“录屏与系统录音”的开关仍显示开启，旧授权也可能不适用于新版。固定应用名或 Bundle ID 不能解决这个问题。

`scripts/build_macos.sh` 已阻止无签名证书时静默覆盖现有应用。使用稳定代码签名证书构建时，将 `SCREEN_STUDY_SIGNING_IDENTITY` 设置为钥匙串中的有效证书名称，并在后续更新中保持同一签名身份。没有证书的开发测试仍可设置 `SCREEN_STUDY_ALLOW_ADHOC_UPDATE=1`，但必须接受更新后可能需要刷新授权；不要反复重建当前已授权的应用。

临时签名版本更新后无法截图时，完整退出应用，在系统设置的“隐私与安全 → 录屏与系统录音”移除旧条目，再添加当前 `dist/ScreenStudyAssistant.app` 并允许，然后重新打开。仅刷新本应用的条目，无需修改其他应用权限。

## 使用

1. 填写 **API URL、API Key、模型名称**。接口需兼容 Chat Completions。
2. 点击“测试连接”，成功后保存设置。
3. 点击快捷键录入框，按下新的组合键并保存。macOS 默认 `⌘ ⇧ K`。
4. 在浏览器、PDF 阅读器等软件中按快捷键，拖动框选文字。
5. 查看 AI 解释、修改识别文字或继续追问；按 Esc 或 × 关闭悬浮窗。

| 系统 | 默认快捷键 | 启动方式 |
|---|---|---|
| macOS | Command + Shift + K | `start.command` / 本机已打包的 `.app` |
| Windows | Ctrl + Shift + K | `start.bat` / 在 Windows 打包后的 `.exe` |

两种系统均可在设置页录入新组合键并保存。Windows 从源码启动时使用本地 RapidOCR，`start.bat` 会安装所需依赖；需要已安装 Python 3.11 或更新版本。Windows 打包脚本为 `scripts/build_windows.ps1`，应在 Windows 上运行。本次尚未执行 Windows 实机验证。

关闭设置页后，应用仍在菜单栏运行。完全退出使用菜单栏图标的“退出”。首次截图需按 macOS 提示授予应用屏幕录制权限并重启。

## 主要功能

- 液态玻璃设置页，卡片、输入框和次要按钮使用更明显的浅灰蓝磨砂底色及边框。macOS 标题栏与正文共用覆盖整个窗口的玻璃和模糊层，去掉中间的圆角断层，保留系统红黄绿按钮和常规窗口操作；API Key 默认隐藏，密钥保存在系统凭据库。
- 可自定义全局组合键，检测冲突，录入期间暂停原快捷键。
- macOS Apple Vision 本地 OCR，无需图片模型，无需下载 OCR 权重。
- 文本 AI 接口、流式回答、停止、追问和重试。
- 回答浮窗采用聊天气泡：你的问题靠右、AI 回答靠左。追问发送后立即显示原始问题和等待状态，随后逐步填入回答；不会等答案完成才显示问题。查看早先消息时，流式更新不强制拉回底部。
- 系统提示词要求每次回答正文最多 500 字，追问同样遵守；先给结论，仅保留必要解释和关键步骤，不凑字数。
- 短缩写或缺少关键条件时先给出 2–4 个方向选项；最后一栏直接提供“其他”输入框，填写后按回车继续回答。同一次截图最多澄清一次，选定方向后直接解释已有信息，不再反复追问；修改原文重试时保留已确认的方向。
- 在同一次模型请求中整理问题和判断是否需要确认，不额外请求生成笔记标题。模型需遵循学习问答输出协议；协议不完整时可在“原文”中修改后重新解答。
- 可拖动及关闭的悬浮窗。
- macOS 使用清透的原生玻璃背景，叠加少量原生模糊以降低过度透底，正文区域保持透明；旧系统保留模糊背景兼容方式。
- 设置页与悬浮窗使用同一套玻璃背景。macOS Clear 玻璃的磨砂强度支持即时调整：在本地应用配置目录的 `appearance.json` 写入 `{"blur_strength":0.4}`（0–1，越大越磨砂），窗口会自动更新。调整此文件无需重新打包或刷新录屏授权；文件不包含密钥，也不写入应用签名包。
- 一次截图及其追问合并成 `学习笔记.md` 中的一条笔记：问题整合为一段完整提问，回答按知识点去重整理。后台更新同一条记录，保留数学题条件和公式，不直接存 OCR 原文；不同截图之间使用分隔线，确认选项期间不写入笔记。
- 文字知识卡片与重复概念提醒；不保存原始截图。

## 数据

默认笔记目录为 `~/Documents/屏幕学习笔记`，可在设置页修改。

截图仅在内存中处理；在线模型会接收识别文字和当前问答上下文。整份本地笔记库不上传，不使用数据库。追问完成后，后台使用本次截图的已完成问答调用文本模型整理一条笔记，不读取其他笔记；知识卡片生成也会额外调用一次文本模型。这些请求失败不影响回答和完整问答的本地保存。

## GPU 识别与悬浮窗入口

Windows 默认使用 DirectML GPU 识别，无兼容 GPU、驱动不可用或 GPU 识别失败时自动使用 CPU。集成显卡也可能支持加速，不要求独立 NVIDIA 显卡。可在唯一的设置页选择“自动”或“仅使用 CPU”；回答窗“原文”按钮的提示显示实际后端、识别用时与回退原因。OCR 引擎在进程内复用，模型随依赖包提供，不在截图时下载。

Windows 请运行 `start.bat`，打包用 `scripts/build_windows.ps1`。旧环境会在升级时替换互相冲突的 ONNX Runtime 包；DirectML 与 CPU 回退共用同一个 `onnxruntime-directml` 包。当前以 Windows 10 / 11 x64 为目标，需要安装适用版本的 Python，首次安装需联网。

悬浮窗使用 28px 圆角、半透明玻璃与高光边缘。macOS 26 及以上接入原生 `NSGlassEffectView`，较旧 Mac 使用原生磨砂背景；Windows 11 尝试系统 Acrylic，旧系统保留半透明效果。系统关闭透明效果时会影响实际观感。

松开选区后，悬浮窗优先出现在右侧，空间不足时依次尝试左侧、下方和上方，并限制在当前显示器可见范围内。整个屏幕的大选区无法完全避让时，选择重叠较少的位置。

关闭设置页或回答窗后会出现可拖动的磨砂玻璃胶囊：默认收起为带柔和彩色微光的小入口，鼠标移入或点击后平滑展开，保留“框选 / 设置 / 笔记”三个操作。点击“设置”重新打开主页面，点击“笔记”直接打开 `学习笔记.md`。移开鼠标稍后自动收起，也可按 Esc 收起；拖动胶囊边缘可移动，展开和收起均限制在所在显示器的可见范围内。回答窗底部也有“笔记”，菜单栏 / 系统托盘仍提供入口。再次双击启动程序也会唤起已运行实例的设置页。关闭回答会停止当前生成，已保存笔记保留。

验证：Mac 本地 OCR 与 RapidOCR CPU 均使用生成的文字图片实测；Windows GPU 选择、回退、会话参数、缓存和定位采用模拟测试。当前没有 Windows 实机，尚未完成实际 GPU 性能与 Windows 玻璃效果验证。

悬浮窗进一步精简：移除顶部图标、产品名称、英文名称和完成提示。只保留正文、追问输入和必要操作，设备诊断放在“原文”提示中；处理中和出错时仍显示状态。


## 一个文件，后台记笔记

新的截图问答统一写入保存位置下的 `学习笔记.md`。一次截图只占一条记录，后续追问更新该记录。问题正文加粗，一段话可包含多个问题；回答合并重复内容并保留关键结论、例子与公式，时间与分隔线区分不同截图，不再生成“问题 1 / 回答 1”这类大标题。历史条目没有可靠的截图关联信息，保留原样，不猜测合并。

完成回答后立即恢复追问操作，后台先将所有已完成问答保存到当前截图的同一条记录，再异步整理；首次回答无需额外整理请求。整理失败或退出取消请求时，仍保留一条完整记录；继续追问会重新整理。关闭回答窗不取消笔记整理，退出会等待已排队的磁盘写入完成。会话 ID、版本和可恢复写入状态存于隐藏的 `.学习笔记索引.json`，正文没有内部编号。迟到的整理不会覆盖新的追问；若当前条目被外部编辑，拒绝覆盖并提示保存失败，其他条目和手动添加的内容不改动。

```markdown
*2026-10-14 12:00:00*

**什么是对比学习，能举一个例子吗？**

让相似样本靠近，不同样本远离。例如，同一只猫的两张照片应有相近的表示。

---

*2026-10-14 12:01:00*

**三角形的面积如何计算？**

已知底为 $a$、高为 $h$，面积为 $ah/2$。
```


## Mac 权限与反复输入密码

打包版本的屏幕录制权限对象是 `ScreenStudyAssistant`，源码版本可能是 Python / 启动终端。当前本地开发包使用临时签名，重新打包后签名标识会改变；系统列表中的旧开关即使显示开启，也可能仍关联旧版本。此时先完整退出应用，在“录屏与系统录音”中移除该应用条目，重新添加现在启动的 `.app` 并开启，再打开应用。发行版本应使用同一个有效的 Developer ID 签名，当前没有配置该证书。

Mac 应用菜单“退出”与 `⌘Q` 已接入真正的退出流程，关闭设置页或回答窗则保留后台运行。权限请求成功会立即继续；拒绝后同一进程不再反复弹出授权请求，可在系统设置授权后重试。

屏幕录制检查先于密钥读取，缺少截图权限时不会再同时读取钥匙串。API Key 只在首次使用对应接口时读取，并在应用进程内复用；手动保存新 Key 后直接更新内存值，清除密钥或切换接口时更新缓存，退出时清除缓存。密钥不会写入配置或笔记。首次读取是否要求身份验证仍由 macOS 钥匙串决定，应用不会跳过系统验证。


## 公式与笔记排版

回答窗在本地使用 MathJax → SVG 渲染公式，支持 `\boxed{…}`、分数、上下标、根号、矩阵等常见 TeX 表达式，以及 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 分隔符。也兼容 `[ \boxed{5} ]` 和裸写的 `\boxed{5}`。不需要多模态模型、Node 运行时或联网加载资源。复制保留模型原文；未完成或不支持的公式回退为文本，代码块与代码示例保持原样。

笔记保持单个 `学习笔记.md`。追问的内容整合由后台文本模型完成，仅发送当前截图的已完成问答，要求最多 500 字并保留各问题的关键内容。排版处理在本地完成：问题加粗，Markdown 标题改成普通加粗文字，保留段落、列表和代码；行内公式规范为 `$…$`，独立公式规范为 `$$` 块，适用于支持数学扩展的 Markdown 编辑器（例如 Typora）。本地排版不改变措辞或数学内容。

首次打开或追加旧版总笔记时，将旧的内部编号移到隐藏索引，整理旧条目的标题与公式，并先保留 `.学习笔记排版前备份.md`。手动添加的开头与代码示例不改动，旧版单独的问答/图鉴文件仍保留。隐藏索引用于避免重复追加、恢复已写入但索引未完成的任务；无需数据库。

公式引擎源码与锁定依赖在 `tools/math-renderer/`，运行 `npm ci && npm run build` 可重新构建随应用打包的资产。构建工具只用于开发；Python 打包脚本已收集公式资产。可用 `python scripts/render_math_preview.py /path/to/previews` 查看离线排版示例。
