# 第一版实现说明

日期：2026-10-14

本轮实现按最新需求收窄界面：**一个模型配置页面 + 可关闭的回答悬浮窗**。不新增笔记管理或知识图鉴页面，笔记与卡片直接在本地文件夹中打开和编辑。

## 已实现

- iOS 风格的浅色设置界面、圆角卡片和蓝色操作按钮。
- API URL、API Key、模型 ID、密钥显示 / 隐藏、清除、连接测试与保存。
- 密钥存入系统凭据库，其他设置存为本地 JSON。
- 可录入全局快捷键，默认 macOS 为 `⌘ ⇧ K`。
- 录入时暂停原快捷键，保存后注册新组合；冲突时保留原快捷键。
- 可先单独保存快捷键，再配置模型。
- 屏幕框选、Esc 取消、缩放坐标裁剪。
- macOS Apple Vision 中英文 OCR，全程在内存中处理图片。
- 文字 Chat Completions API，SSE 流式输出，以及非流式 JSON 回答。
- 回答悬浮窗，28px 圆角原生玻璃、选区旁定位，可拖动、关闭、复制、停止、编辑识别文字及继续追问。
- 聊天式消息气泡，问题靠右、回答靠左；发送追问立即显示问题与等待状态，答案流式更新同一个气泡。保留用户原始提问措辞，模型整理后的问题用于笔记；停止或失败仍保留已发出的问题和部分回答。
- Windows DirectML GPU 优先，GPU 不可用或出错自动 CPU 回退；设置页支持强制 CPU，“原文”提示显示实际设备与耗时；引擎缓存复用。
- 关闭窗口后显示磨砂玻璃胶囊，收起时保留柔和彩色微光；鼠标移入或点击平滑展开“框选 / 设置 / 笔记”，移开自动收起，Esc 收起。胶囊边缘可拖动，靠屏幕边缘展开时保持可见，隐藏后停止微光动画；回答窗仍可直接打开笔记。
- 一次截图及其追问合并成 `学习笔记.md` 的一条记录；问题整合为一段，回答后台去重整理，不使用编号大标题。
- 后台提炼主要概念并保存文字知识卡片；按名称 / 别名匹配旧概念并提醒。
- 托盘菜单、重复启动检测、macOS 本地应用打包。

## 使用步骤

1. 双击 `dist/ScreenStudyAssistant.app` 或 `start.command`。
2. 填写 API URL、模型 ID 和自己的 API Key。
3. 点击“测试连接”，成功后“保存设置”。
4. 点击快捷键录入框，按下希望使用的组合键，再保存设置。
5. 在其他软件按下该快捷键，框选清晰文字。
6. 查看解释、追问，或关闭悬浮窗返回阅读。

模型地址支持基础地址，例如 `https://your-provider.com/v1`，也支持粘贴完整的 `…/chat/completions` 路径。接口需兼容聊天请求格式；任意 URL 可填写并不代表任意 API 协议都可用。本地免鉴权服务可留空 API Key。

首次截图时，macOS 可能要求屏幕录制权限。给 `ScreenStudyAssistant` 授权后重启应用；从源码运行时，授权对象可能是终端或 Python。热键使用系统注册，不监听键盘输入，无需为热键额外启用辅助功能。

## 本地保存

默认笔记目录：`~/Documents/屏幕学习笔记`，可在设置页选择新位置。

```text
屏幕学习笔记/
├── 学习笔记.md
└── 知识图鉴/概念名称-ID.md
```

截图不会保存，配置文件不包含 API Key。在线模型会收到 OCR 文字与当前追问上下文，不会收到整份笔记库。自动知识卡片提炼会额外调用一次文本模型；卡片失败不影响问答保存。新卡片状态为“初次遇见”，个人理解留空，用户可直接在 Markdown 中编辑。

## 验证与限制

- 单元及集成测试覆盖真实本地 OCR、缩放裁剪、API 请求与错误、流式中断、追问保存、卡片重复匹配、密钥分离和原生快捷键冲突恢复。
- 网络层及完整 OCR → 问答 → 卡片流程使用模拟模型响应测试，不消耗用户账户额度。
- 用户尚未提供真实服务配置，真实模型返回效果需要在页面填写后验证。
- 当前机器上实现与验证的是 macOS Apple Silicon 版本。Windows / Linux 的兼容分支尚未在对应系统上验证。
- 普通 OCR 以印刷文字为主，复杂公式、图表和几何题不承诺正确识别。
- 数学公式目前作为文本显示，尚未接入完整 LaTeX 渲染。
- 第一版按名称和别名查重，不做语义知识地图；同名异义的复杂概念建议手动核对卡片。
- 回答尚未完成时关闭悬浮窗会取消请求；已完成且保存的问答会保留。

## 开发

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m screen_study_assistant
python -m pytest -q
```

macOS 打包：`scripts/build_macos.sh`。从截图到答案的所有功能都是实际代码，界面预览脚本使用的示例内容仅用于布局检查。

笔记文件写入、概念查找和卡片写入使用独立后台队列，不在 GUI 线程运行。界面在收到完整回答后立即允许追问；同一次截图先将已完成问答更新到一条记录，再用独立后台请求合并问题和回答。整理只发送该截图的已完成问答，不读取其他笔记。整理失败时保留完整内容，版本检查防止迟到的摘要覆盖新追问。关闭悬浮窗不取消整理；退出时可取消模型请求，但仍完成磁盘写入。外部编辑的当前条目拒绝覆盖，其他条目保持原样。旧版本笔记缺少截图关联信息，原样保留。
